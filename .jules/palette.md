## 2024-05-08 - Added keyboard accessibility and focus styles to message list
**Learning:** List items like `div.message-row` without explicit `tabindex="0"` cannot be focused or interacted with by keyboard users or screen readers. Also, elements acting as buttons (like `span.msg-bookmark`) must be `<button>` elements to be natively accessible without writing custom Javascript to handle SPACE/ENTER keydowns and ARIA roles. Focus visibility provides a massive UX win for keyboard users but is often missed in custom layouts without a global `*:focus-visible` CSS rule.
**Action:** When creating custom list items that have an `onclick` handler, explicitly set `tabindex="0"`, `role="button"`, and handle keyboard interactions. Use native `<button>` elements for inline actions rather than clickable spans. Add a global `:focus-visible` rule.
