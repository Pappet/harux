What changed & why

01 · Top bar

Health pills replace dot stats

The MLLP listening port, connection count, throughput rate, time-since-last-message and error count are now first-class. :2575 is visible at a glance, and the rate pill carries a 60-second sparkline so you can see trend, not just instant.

02 · Throughput band

60-second bar histogram above the list

Lets you spot bursts, gaps, or quiet hours without leaving the inbox. Counters next to it (total / per-min / warnings / errors) summarise what the bars show.

03 · Source rail

Always visible, click to filter

Source is a primary discrimination axis when you have multiple senders. Pulling the legend out of the hidden state and giving each source a count makes it useful as a filter, not just a key.

04 · Message row

Two-line layout, hierarchy by typography

Type + patient + ACK on line 1 (the answer to "what is this?"), facility · source · time on line 2 (metadata). The 9-column grid is gone — eyes anchor to the bold row 1.

05 · Time grouping

Sticky "Live / Earlier today" headers

Live debugging is about "what just happened?" Grouping by recency answers that without making you parse timestamps. Older sections collapse implicitly.

06 · ACK as colored chip

Scannable AA / AE / AR

Green for AA, red for AE, amber for AR. You can spot a row of failures from across the room. Same applies to validation badges (⚠ 2, ✕ MISSING_SEG).

07 · Bookmark only

Pin-for-diff moves out of the row

Two icons per row was too much. Bookmark stays (★ on hover, persistent when set). Pin-for-diff is a contextual action in the detail header — that's the only place it semantically fits.

08 · Detail header

Title is human, metadata is monospace

"Admit/Visit Notification" reads first; ADT^A01 chip beside it. MRN, control ID and timestamp sit on their own metadata line with copy-to-clipboard handles.

09 · Typical segments + warnings panel

Severity is unmissable

The typical-segments bar uses pill states (✓ present, ⚠ warn, ✕ missing, dim absent). A summary banner above the segment blocks names the offending fields directly — no hunting through the list to find the ⚠.

10 · Empty state (not shown)

Show config + a sample CLI

"Listening on :2575, no messages yet" with a copy-able echo <MSG> | mllp-send … command would turn the empty state from dead air into self-serve help.
